# মেশিন লার্নিং, সহজ ভাষায়

মেশিন লার্নিংয়ের ১৩৩টি টার্মের একটি ছোট বাংলা গাইড, যাঁরা এই বিষয়ে একদম নতুন তাঁদের জন্য। ১১টি পর্ব, প্রতিটি টার্ম আলাদা পাতায়, সঙ্গে সার্চ, ইন্টারঅ্যাকটিভ উদাহরণ ও পর্বভিত্তিক কুইজ।

**লাইভ লিংক** https://aazabir.github.io/ml-terms/

শুধু HTML, CSS ও vanilla JavaScript দিয়ে বানানো। কোনো বিল্ড স্টেপ, ফ্রেমওয়ার্ক, npm প্যাকেজ বা সার্ভার লাগে না। সব লিংক রিলেটিভ, তাই যেকোনো সাবফোল্ডারে চলে।

## কম্পিউটারে চালিয়ে দেখা

ব্রাউজার `file://` থেকে JSON লোড করতে দেয় না, তাই একটি সাধারণ সার্ভার দিয়ে খুলতে হবে।

    python3 -m http.server 8000

তারপর http://localhost:8000/ খুলুন।

## ফোল্ডার

    index.html        সূচিপত্র (হোমপেজ)
    chapter.html      ?c=01 পর্বের টার্ম তালিকা, ?c=01&t=টার্ম-আইডি একটি টার্ম
    quiz.html         ?c=01 পর্বের কুইজ
    css/style.css     সব রং CSS ভ্যারিয়েবলে (:root ও [data-theme="dark"])
    js/               app.js, search.js, quiz.js, theme.js
    js/interactives/  প্রতিটি ইন্টারঅ্যাকটিভ আলাদা ফাইলে
    data/             chapters.json, ch-01.json ..., quiz-01.json ...

## কনটেন্ট এডিট করা

সব লেখা `data` ফোল্ডারের JSON-এ আছে, HTML-এ কিছু হার্ডকোড করা নেই।

**বইয়ের নাম, ভূমিকা, সহজ করার নোট ও পর্বের তালিকা** `data/chapters.json`-এ। প্রতিটি পর্বে `total` (মোট টার্ম), `written` (কতটি লেখা হয়েছে), `quiz` (কুইজ তৈরি হলে `true`) এবং `terms` (পরিকল্পিত টার্মের ইংরেজি নাম) থাকে। নতুন টার্ম যোগ করলে `written` বাড়াতে হবে। `written` শূন্য থাকলে পর্বটি "শীঘ্রই আসছে" হিসেবে ফিকে দেখায়।

**টার্ম** `data/ch-01.json` (পর্বের নম্বর অনুযায়ী) ফাইলে টার্মের তালিকা। একটি টার্ম এরকম।

    {
      "id": "overfitting",
      "bn": "ওভারফিটিং",
      "en": "Overfitting",
      "simple": "বাংলা সংজ্ঞা, সরাসরি শুরু করুন (\"সহজ কথায়\" লিখতে হবে না)",
      "simpleEn": "The same definition in English.",
      "body": ["অনুচ্ছেদ ১", "অনুচ্ছেদ ২", {"h": "উপশিরোনাম"}],
      "table": {"headers": ["ক", "খ"], "rows": [["১", "২"]], "caption": "ঐচ্ছিক"},
      "tableAfter": 1,
      "interactive": "overfit-chart"
    }

- `simple` বাঁ পাশে মোটা দাগে আলাদা বাক্সে দেখায়, তার নিচে `simpleEn` ইংরেজি সংজ্ঞা হালকা লেখায়।
- `id` ইংরেজি ছোট হরফে ও হাইফেনে, এটাই URL-এ ব্যবহার হয়।
- `body`-র প্রতিটি লেখা একটি অনুচ্ছেদ। `{"h": "..."}` দিলে উপশিরোনাম হয়।
- `table` না লাগলে `null`। `tableAfter` বলে কতটি অনুচ্ছেদের পর টেবিল বসবে (না দিলে ১)।
- `interactive` না লাগলে `null`। দিলে `js/interactives/<নাম>.js` লোড হয়।
- টার্মের ক্রম বদলাতে চাইলে ফাইলে অবজেক্টের জায়গা বদলান। আগের ও পরের টার্মের লিংক এবং সার্চ নিজে থেকেই ঠিক হয়ে যাবে।

**কুইজ** `data/quiz-01.json` ফাইলে প্রশ্নের তালিকা। তৈরি করার পর `chapters.json`-এ ওই পর্বের `quiz` মান `true` করুন।

    {"q": "প্রশ্ন", "options": ["ক", "খ", "গ", "ঘ"], "answer": 1, "explain": "ব্যাখ্যা"}

`answer` হলো সঠিক অপশনের ইনডেক্স, ০ থেকে ৩। সর্বোচ্চ স্কোর ব্রাউজারের localStorage-এ জমা থাকে।

## নতুন ইন্টারঅ্যাকটিভ যোগ করা

1. `js/interactives/` ফোল্ডারে নতুন ফাইল বানান, যেমন `my-demo.js`।
2. ফাইলে নিজেকে রেজিস্টার করুন। ফাংশনটি একটি খালি কন্টেইনার পায়, তার ভেতরে সব আঁকতে হবে।

        (window.Interactives = window.Interactives || {})['my-demo'] = function (box) {
          // ML.h দিয়ে এলিমেন্ট বানান, SVG বা Canvas দিয়ে আঁকুন
        };

3. টার্মের JSON-এ `"interactive": "my-demo"` লিখুন।

নিয়ম হলো কোনো বাইরের লাইব্রেরি নয়, রং শুধু `var(--fg)`, `var(--bg)` ইত্যাদি CSS ভ্যারিয়েবল থেকে (যাতে লাইট ও ডার্ক দুই মোডে পড়া যায়), আর স্লাইডারে লেবেল ও বাংলা সংখ্যায় মান দেখানো। `ML.bn(n)` ইংরেজি সংখ্যাকে বাংলায় বদলে দেয়। হিসাবের অংশ আলাদা বিশুদ্ধ ফাংশনে রাখলে Node দিয়ে যাচাই করা সহজ হয়, উদাহরণ `js/interactives/route-learning.js`।
